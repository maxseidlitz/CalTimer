Kalender per Link freigeben

CalTimer bekommt kein iCloud-Passwort. Stattdessen gibst du einzelne Kalender über einen geheimen Link frei – CalTimer kann damit nur diese Termine lesen, nichts sonst.

  1. iPhone: Kalender-App → unten Kalender → (i) neben dem gewünschten Kalender.
  2. Öffentlicher Kalender einschalten → Link teilen … → Kopieren.
  3. Link hier einfügen. Für weitere Kalender einfach wiederholen.

Behandle den Link wie ein Passwort: Wer ihn kennt, kann diesen Kalender lesen. Ausschalten und wieder einschalten erzeugt einen neuen Link.
